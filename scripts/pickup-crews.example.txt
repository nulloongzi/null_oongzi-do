#
#   node scripts/seed-pickup-crews.js data/pickup-crews-seoul.txt --region 서울 --english
#   (확인 후) 같은 명령에 --commit 추가
#
# 규칙
#   · 한 줄에 하나. 빈 줄과 이 줄 같은 `#` 주석은 무시.
#   · `?igsh=...` 추적 파라미터는 자동으로 떨어진다.
#   · `|` 뒤는 선택 — 두 번째=표시 이름, 세 번째=지역(생략 시 --region 값).
#   · 이름을 안 주면 핸들이 그대로 제목이 된다. 목록 카드에서 핸들이 두 번 보이니
#     크루가 실제로 쓰는 이름을 아는 경우엔 채워주는 편이 낫다.
