# 마케팅 전략 — 누룽지도 리론치 + 초기 성장

> 출발점: `docs/handoff-deploy-marketing.md`. 배포 준비의 기술 측면은 앱 레포
> `null_oongzi-do-app/docs/deploy-readiness.md` 참고. 이 문서는 **마케팅 전략**을 다룬다.

## 0. 현실 프레이밍
- **콜드 런칭 아님 → "리론치 + 초기 성장."** 이미 Google Play에 있으나 **10+ 다운로드**로
  사실상 제로베이스.
- 이번 릴리즈의 스토리: **웹뷰 → 네이티브 재작성** = "부드럽고 빠른 앱, 끊김 없는 지도, 정상 로그인."
- 타깃: ① 배구 동호회 가입 희망자 ② 픽업 게임 참가자 ③ 동호회 총무(공급측). KO 우선, EN 지원.
- **핵심 자산 = 이미 라이브인 웹(nulloongzido.com) + 인스타 플라이휠**(딥링크·스토리카드·릴스 임베드).
  마케팅은 새 채널을 만드는 게 아니라 **이 플라이휠에 앱 설치를 얹는** 일.

## 1. 두 시나리오 (서명 키 갈림길에 따라)
`deploy-readiness.md §1-2` 결과에 따라 마케팅 프레이밍이 갈린다:
- **시나리오 A — 같은 리스팅 업데이트(권장 상태):** 기존 다운로드/리뷰 유지. 메시지 =
  **"앱이 새로워졌어요"**(업데이트 소구). 기존 설치자에게도 재활성 푸시 여지.
- **시나리오 B — 신규 리스팅(키 분실 등):** 다운로드/리뷰 리셋. 메시지 = **신규 출시**로 전환,
  구버전 리스팅은 신버전으로 유도(설명에 링크). 리뷰 0부터 시작하므로 **초기 리뷰 확보**가 더 중요.

## 2. 포지셔닝 & 메시지
- 한 줄: **"전국 배구 동호회를 지도 한 눈에 — 내 근처 팀·픽업 게임 찾기."**
- 차별 기능(경쟁 앱/카페 검색 대비):
  - 🗺️ **지도 기반 탐색** — 지역/요일/대상(남·여·혼복·6인제) 필터.
  - 🏐 **픽업 게임** — 오늘/이번주 즉석 참여, 익명 등록.
  - 🍱 **도시락(찜)** + 🍚 **밥이름 닉네임** — 가볍고 친근한 브랜드 톤.
  - 🌏 **English-OK** — 외국인도 팀 찾기(표시만 EN, 6인제 강조).
  - 🔗 **공유가 쉬움** — 팀/스팟 딥링크 + 스토리카드(인스타 최적).
- **불변 톤 유지:** 환대 > 위상. 랭킹/별점/순위 없음 — "모두 환영" 메시지로 밀 것
  (`null_oongzi-do-app/docs/HANDOFF.md` 불변 규칙과 정합).

## 3. 채널 전략 (우선순위)

### 3-1. 배구 커뮤니티 침투 (최우선, 저비용·고적합)
- 네이버 카페(지역 배구 동호회·생활체육), 오픈채팅, 동호회 밴드에 **공급측(총무) 등록 유도**.
  - 앵글: "우리 팀을 지도에 무료 등록 → 신입 문의가 지도에서 들어옴." 공급이 수요를 부른다.
- 대학/직장인 배구 소모임, 생활체육회 연계.
- KPI: 등록 클럽 수, 지역 커버리지(빈 지역 = 성장 여지 시각화).

### 3-2. 인스타/릴스 플라이휠 (이미 구현된 자산 활용)
- 스토리카드(1080×1920 + QR + 지하철역) → 총무가 팀 홍보 시 자연 배포 → 딥링크로 앱/웹 유입.
- `insta_reel` 임베드 → 팀 릴스가 앱 안에서 재생 → 팀이 스스로 홍보 동기.
- 앵글: "팀 릴스 올리면 지도에서 미리보기로 뜬다" → 공급측 콘텐츠 유도.
- KPI: 스토리카드 공유 수, 딥링크 유입(`?club=`/`?spot=`), 임베드 조회.

### 3-3. 웹 → 앱 유입 (라이브 자산 전환)
- nulloongzido.com 방문자(미설치자)에게 **스마트 배너/설치 유도** + 딥링크로 앱 열기(폴백 웹).
- 웹은 SEO·미설치자 즉시 진입 깔때기로 유지(`NATIVE_REWRITE_PLAN.md` 정합) — 폐기하지 않음.
- KPI: 웹 세션 → 앱 설치 전환율, 딥링크 앱오픈 비율.

### 3-4. 유료 광고 (선택, 예산 확보 시)
- 소액 Google/Meta 앱 설치 캠페인 — "배구 동호회" 키워드/관심사 타깃. 유기 채널 검증 후 확대.
- 초기엔 3-1/3-2에 집중, 유료는 나중.

## 4. 스토어 최적화 (ASO)
- 제목/설명에 핵심 키워드: **배구, 동호회, 픽업 게임, 배구 지도, 배구 모임**.
- 스크린샷 **네이티브 전환 반영해 교체** — 지도/필터/픽업/도시락/공유 순으로 핵심 기능 시연.
- "무엇이 새로운가": 웹뷰→네이티브, 빠른 지도, 로그인 개선 명시.
- 초기 리뷰 확보(특히 시나리오 B): 등록 총무·초기 사용자에게 리뷰 요청(앱 내 넛지는 과하지 않게).

## 5. 실행 로드맵
- **T-0 (배포 직전):** 스토어 리스팅/스크린샷 갱신, 내부 테스트 스모크, 개인정보처리방침 최신화.
- **주 1 (소프트):** 배구 카페/밴드 3~5곳에 총무 등록 유도 글, 웹 배너 켜기. 반응·등록 수 관찰.
- **주 2~4 (성장):** 스토리카드/릴스 플라이휠 독려, 빈 지역 집중 공략, 리뷰 확보.
- **월 2+ (확대):** 유기 지표 검증 후 유료 소액 테스트, 필요 시 iOS 확장 검토.

## 6. 측정 (이미 있는 Analytics 활용)
- 앱 `lib/services/analytics.dart`(12+ 이벤트)로 설치 후 핵심 퍼널 측정:
  탐색 → 상세 → 도시락/공유 → 등록. Firebase Analytics 대시보드로 주간 리뷰.
- 북극성 지표 후보: **주간 활성 탐색자 수** + **등록 클럽/픽업 수**(공급) — 환대 철학상 순위 지표 지양.

## 7. 사람이 결정/실행할 것
- 시나리오 A/B 확정(서명 키 결과, `deploy-readiness.md §1-2`).
- 초기 침투할 배구 커뮤니티 목록 선정 + 총무 컨택.
- 스크린샷/스토어 카피 최종본, 유료 광고 예산 여부.
- iOS 포함 시점.
