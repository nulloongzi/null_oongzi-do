# 누룽지도 모션 정의서 — 웹앱 · 네이티브 앱

> 화면이 **어떻게 움직이는지**를 적은 문서다. 무엇이 있고 누르면 무슨 일이 생기는지는 `docs/ui-ux-spec.md`,
> 색·모서리·그림자는 `docs/design-system.md`.
> 기준: 웹 main `688fde0` · 앱 main `c944101`. 작성 2026-10-22, 양쪽 코드에서 애니메이션 값을 전부 모았다.
> 값은 코드에 적힌 그대로다. 코드가 값을 안 정해 라이브러리 기본값이 쓰이는 곳은 "기본값"이라고 밝혔다.

## 0. 이 문서 쓰는 법

**모션을 바꾸거나 새로 넣고 싶을 때** 이렇게 말하면 된다.

- "필터 시트를 **M01 바텀시트 올라오기**로 바꿔 줘" — §2 이름표의 이름으로 부른다.
- "도시락 칸을 바꿀 때 **모션 없음** 대신 두 칸이 자리를 바꾸며 미끄러지게" — §3 표에서 "즉시"로 적힌 곳이 모션을 넣을 후보다.
- "시트 시간을 웹·앱 다 **250ms**로 맞춰" — §4 에 지금 서로 다른 값이 모여 있다.

**읽는 법**

- 시간은 ms(1000ms = 1초). 사람 눈에 150ms 는 '탁', 250~300ms 는 '스윽', 400ms 넘으면 '천천히'로 느껴진다.
- 곡선(이징)은 §1 의 별명으로 부른다. 같은 시간이라도 곡선에 따라 느낌이 완전히 다르다.
- **즉시** = 모션 없이 한 프레임에 바뀜.
- 근거 줄 번호는 부록 A(웹, 패턴 번호 `W`)·B(앱, 패턴 번호 `F`)에 있다. 본문은 읽기 쉽게 값과 느낌만 적었다.

## 1. 곡선 별명

| 별명 | 실제 값 | 느낌 | 어디서 쓰나 |
|---|---|---|---|
| **감속** | 웹 `cubic-bezier(0.2, 0.8, 0.2, 1)` · 앱 `Easing.legacyDecelerate (0,0,0.2,1)` · 앱 `easeOutCubic` | 빠르게 출발해 부드럽게 멈춤. 시트·패널의 기본 | 웹 상세·필터 시트, 식단표 / 앱 모달 시트, 시트 스냅, 식단표 |
| **튕김** | 웹 `cubic-bezier(0.34, 1.56, 0.64, 1)` · 앱 `Curves.easeOutBack` | 목표를 살짝 넘었다가 돌아옴. 통통 튀는 귀여움 | 웹 프로필 카드·FAB 눌림 / 앱 도시락·프로필 팝업, 눌림 바운스 |
| **약한 튕김** | 웹 `cubic-bezier(0.34, 1.4, 0.64, 1)` | 튕김보다 덜 넘침 | 웹 앱 설치 배너 |
| **부드럽게** | CSS `ease` · 앱 `Curves.ease`·`easeOut` | 무난한 시작·끝 | 대부분의 색 전환, 짧은 팝업 |
| **등속** | `linear` | 처음부터 끝까지 같은 속도. 기계적 — 회전·반복 효과가 아니면 대개 '곡선을 안 정해서' 생긴 것 | 앱 탭 알약·점·롤링 띠·팝업 페이드(곡선 미지정) |
| **강조 전환** | 앱 `easeInOutCubicEmphasized` | 안드로이드 화면 넘김 기본. 끝에서 길게 감속 | 앱 전체 화면 전환 |

## 2. 모션 이름표

## 3. 기능별 모션 표

"누르면 → 무엇이 → 어떻게" 를 기능마다 적었다. **굵은 즉시**는 지금 모션이 없는 곳 — 모션을 넣을 후보다.

### 3-1. 지도

| 트리거 | 무엇이 | 웹 | 앱 |
|---|---|---|---|
| 앱 실행 | 첫 화면 → 지도 | (해당 없음) | 시스템 스플래시(크림 + 로고) → 지도 **즉시** |

### 3-3. 동호회 상세

| 트리거 | 무엇이 | 웹 | 앱 |
|---|---|---|---|
| 마커 탭 | 지도 → 시트 | M16 확대·이동과 **동시에** 시트 0→390px 300ms | M16 과 **동시에** 패널 0→42% 300ms |

## 4. 맞지 않는 곳 · 고칠 후보

같은 성격인데 값이 다르거나, 웹·앱이 다르거나, 코드상 버그로 보이는 것.

**같은 성격, 다른 값**
1. ~~바텀시트 4가지가 다 다르다~~ — **맞춤(2026-10-22, §5)**: 상세 시트 300/250ms, 모달 시트 250/200ms 두 가지로 정리하고 토큰으로 묶었다. 웹 픽업 패널(고정 높이)만 남음.
2. **가운데 팝업이 두 체계** — 튕김 스프링(프로필·도시락) vs 짧은 페이드(확인창·공유 메뉴). 웹은 등록·신고·인증·급구·모집·미리보기 팝업이 **아예 모션 없음**.
3. **배경 어둡게**가 150/250/300ms 와 '즉시'가 섞임(웹).
4. **눌림 바운스**가 웹에선 8가지 크기 × 여러 시간, 앱은 0.94·120ms 하나.
5. **펼치기**가 앱에서 220ms easeOut(상세) / 320ms easeOutCubic(식단표) / 200ms easeIn(접는 카드) 세 가지.
6. **곡선을 안 정해 등속으로 도는 것**(앱): 탭 알약 180ms, 점 220ms, 롤링 띠 400ms, 도시락·프로필 팝업 페이드 300ms, 🍱 투명도 150ms.

**웹 ↔ 앱이 다른 것**
7. ~~상세 시트 열기가 다름~~ — **맞춤(§5)**: 둘 다 카메라와 동시에 아래에서 올라온다.
8. ~~상세 닫기가 다름~~ — **맞춤(§5)**: 둘 다 250ms 가속으로 내려간다.
9. ~~시간표 모프가 다름~~ — **맞춤(§5)**: 둘 다 시트 높이에 매 프레임 묶인다.
10. 도시락 열기: 웹은 상자 모션 없음, 앱은 튕김.
11. 롤링 띠: 나가는 줄이 웹은 즉시 사라지고, 앱은 아래로 흐려짐.
12. 새 신청 점: 웹은 깜빡임 반복, 앱은 고정.
13. 급구 이름표: 웹은 등장 페이드 + 맥박, 앱은 페이드만(맥박 없음).

**닫힐 때 모션이 거의 없다**
14. 웹은 상세·필터 시트, 픽업 패널, 토스트, 앱 배너 말고는 모두 즉시 사라진다. 앱도 상세 패널·릴스 미리보기는 즉시.

**코드상 버그로 보이는 것**
15. ~~웹 로그인 알약(`.al-pill`)이 300ms 동안 오른쪽으로 치우쳤다 툭 가운데로 옴~~ — **고침(2026-10-22)**: 가운데 정렬을 품은 전용 키프레임 `alPillIn`.
16. ~~웹 급구 이름표만 등장 페이드가 없음~~ — **고침(2026-10-22)**: `animation: labelFadeIn …, pulse …` 둘 다 건다.
17. ~~웹 앱 설치 배너가 올라올 때 FAB·픽업 패널이 순간 이동~~ — **고침(2026-10-22)**: 배너가 오르내리는 400ms 동안만 `body.app-banner-moving` 으로 `bottom` 전환(350ms 약한 튕김)을 건다. 늘 걸면 탭 전환 때 FAB 자리 바꿈까지 미끄러져서.
18. 웹 필터 시트는 손잡이를 한 번 끈 뒤부터 열고 닫는 시간이 400→300ms 로 바뀐다(인라인 transition 이 남음).
19. 웹 다시 그리는 화면(🍚 시트 칩, 도시락 칸, 밥친구 화면)은 DOM 을 새로 만들어 CSS 전환이 작동하지 않는다.

**움직임 줄이기 설정**
20. 웹은 롤링 띠·신호 깜빡임·로그인 효과 3곳만, 앱은 로그인 효과 1곳만 따른다. 나머지(시트, 팝업, 지도 카메라, 급구 맥박, 부드러운 스크롤)는 기기의 '애니메이션 줄이기'를 무시한다.

## 5. 바텀시트 기준 (2026-10-22 웹·앱 통일)

**정한 원칙** — "팀을 누르면 시트가 아래에서 쓱 올라오고, 핸들을 잡고 올리면 시간표가 모프되며 나타난다." 손가락과 시트가 한 몸처럼 움직이는 것이 기준이다.

- 상세 시트는 **웹을 기준**으로 맞췄다. 웹은 이미 카메라와 함께 올라오고, 내려가며 닫히고, 끄는 동안 시간표가 모프됐다. 앱은 카메라가 끝난 뒤 툭 나타나고 툭 사라졌다.
- 모달 시트는 **앱(Flutter 기본)을 기준**으로 맞췄다. 안드로이드·iOS 사용자가 이미 익숙한 값이고, 앱 모달 시트 다섯 군데가 모두 이 값이다.
- 양쪽에 없던 것은 새로 넣었다: **빠르게 튕기기**(위치 대신 손 빠르기로 방향 결정), **붙는 동안에도 모프**, **닫힘은 가속 곡선**(빨려 내려가듯).
- 값은 `tokens/design-tokens.json` 의 `motion`·`easing` 하나에서 웹 CSS 변수와 앱 `NurungjiMotion` 으로 생성된다. 바꾸려면 거기만 고치고 `npm run tokens`.

| 시트 | 열기 | 붙기(놓았을 때) | 닫기 | 튕기기 | 모프 |
|---|---|---|---|---|---|
| **상세 시트**(동호회 상세, 앱 픽업 목록·상세) | 아래에서 접힘 높이까지 **300ms** `--ease-sheet`(감속), 카메라와 동시 | **300ms** 감속 | **250ms** `--ease-sheet-exit`(가속) | 800px/s 넘으면 그 방향 | 시트 높이에 매 프레임 |

**일부러 남긴 차이**
- 필터는 웹·앱 모두 **위에서 내려오는 탑시트**다(2026-10-22 결정). 검색바 옆 버튼에서 열리는 시트라 누른 자리에서 펼쳐지는 게 맞다고 봤다. 손잡이는 시트 아래쪽, 위로 끌어 닫는다 — 다른 시트와 방향만 반대다.
- 웹 픽업 목록은 고정 높이 패널이라 끌 수 없다(앱은 끌기 시트). 목록↔상세 높이 변화는 300ms 감속으로 같다.
- 접힘 높이는 웹 390px, 앱 화면의 42%(폰에서 거의 같다).
- '애니메이션 줄이기'를 켠 기기에서는 상세 패널(앱)·🍚 시트(웹)가 모션 없이 바로 바뀐다.

### 부록 A-3. 일관성 문제 (조사 메모)

1. **바텀시트 4종이 서로 다릅니다.**

   | 시트 | 방식 | 길이 |
   |---|---|---|
   | 상세 | 높이 변화 | 300ms DECEL |
   | 필터 | translateY | 400ms (끈 뒤에는 300ms) |
   | 🍚 여기 자리 있어요? | 팝업 키프레임 | 250ms `ease-out` |
   | 픽업 패널 | max-height | 300ms |

   - CSS에 적힌 `.bottom-sheet` 기본값 `0.1s linear`은 쓰이지 않는 코드입니다.
2. **가운데 팝업 3종이 서로 다릅니다.**
   - 프로필 카드: 300ms SPRING
   - 공유 메뉴와 nzDialog: 180ms ease
   - 도시락 상자, 등록·신고·인증·급구·모집 모달, 미리보기: 등장 모션 없음
3. **배경 어둡게 깔기가 서로 다릅니다.** 300ms / 250ms / 150ms가 섞여 있고, 공유 메뉴·🍚 시트·등록 모달·미리보기는 페이드 없이 바로 어두워집니다.
4. **닫기 모션이 거의 없습니다.** 퇴장 모션이 있는 곳은 상세 시트, 필터 시트, 픽업 패널, 토스트, 앱 배너뿐입니다. 나머지 팝업과 시트는 모두 즉시 사라집니다.
5. **눌림 축소가 제각각입니다.** 크기 8가지(0.85~0.99), 길이 0/100/120/150/200/250ms, 곡선은 SPRING과 ease가 섞여 있습니다.
6. **다시 그리는 화면은 전환이 무시됩니다.** 🍚 시트 칩, 도시락 칸 선택·교환, 밥친구 화면 이동은 DOM을 새로 만들기 때문에 CSS transition이 작동하지 않습니다.
7. **버그 2건**
   - `.al-pill`: 등장 키프레임이 `translateX(-50%)`를 덮어써서 300ms 동안 알약이 오른쪽으로 치우쳤다가 툭 가운데로 옵니다.
   - `.label.urgent`: `pulse`가 등장 페이드를 덮어써서 급구 라벨만 페이드 없이 나타납니다.
8. **앱 배너가 올라올 때 FAB은 순간 이동합니다.** `bottom`에 transition이 없습니다.
9. **시간표 모프는 끌 때만 보입니다.** 탭이나 스냅으로 바뀔 때는 내용이 즉시 교체됩니다.
10. **움직임 줄이기 설정을 대부분 무시합니다.** 다음은 모두 처리가 없습니다:
    - 무한 반복: 급구 맥박
    - 등장 모션: `slideUp`, `fadeIn`, `shareMenuIn`, `labelFadeIn`
    - 지도: 카카오 `panTo`·`setLevel` 애니메이션
    - 부드러운 스크롤 전부

### 부록 B-4. 참고
- **모션 줄이기 대응은 로그인 진행 레이어 한 곳뿐**입니다. 그 밖의 Flutter 기본 모션(시트, 팝업, 라우트)은 시스템의 애니메이션 끄기 설정을 따르지 않습니다. 스낵바만 Flutter 내부에서 `accessibleNavigation`일 때 트랜지션을 생략합니다.
- **커브를 지정하지 않아 linear로 도는 모션**: 탭 알약 180ms, 프로필 점 220ms, 롤링 띠 400ms, 도시락·프로필 팝업 페이드 300ms, 🍱 불투명도 150ms. 디자이너가 커브를 맞출 때 1순위 후보입니다.
- **같은 일에 다른 값을 쓰는 곳**: 펼치기가 220ms easeOut(상세) / 320ms easeOutCubic(식단표) / 200ms easeIn(ExpansionTile)으로 세 가지입니다. 팝업도 150ms 페이드(AlertDialog)와 300+340ms 스프링(도시락·프로필) 두 체계로 나뉘어 있습니다.
