# 누룽지도 디자인 시스템 (마케팅·프로덕트 공통)

> 웹·앱·마케팅 에셋(스토어 이미지·블로그·인스타·릴스)이 **한 톤**으로 보이게 하는 고정 규칙.
> 소스 진실: 웹 `css/main.css :root`, 앱 `lib/theme.dart`. 마케팅 에셋은 이 문서를 따른다.

## 2. 타이포그래피
- **폰트: Pretendard 가변(Pretendard Variable) 하나** — 웹·앱·공유 카드·마케팅 전부 동일.
  다른 글꼴을 들이지 않는다(목업·무드보드도 같은 폰트로 본다 — 대체 글꼴로 본 인상은 실제와 다르다).
- 제목 800(ExtraBold), 본문 400~500, 캡션 400. 공유 카드 숫자는 표 7-3.
- 한글 우선, 영문 병기 시 같은 폰트.

| 어디 | 불러오는 방법 |
|---|---|
| 웹 `index.html` | jsDelivr npm `pretendard@1.3.9` 의 `variable/pretendardvariable.css` (전체 파일). 공유 카드를 canvas 로 그리므로 글자별 분할(dynamic-subset)은 쓰지 않는다 — 아직 안 받은 글자가 대체 폰트로 찍힌다 |
| 웹 정적 페이지(`privacy`·`terms`·`guidelines`·`data-deletion`·`anchigi`) | 같은 버전의 `pretendardvariable-dynamic-subset.css` — 화면 글자만 쓰니 나눠 받아도 된다 |
| 앱 | `assets/fonts/PretendardVariable.ttf` 번들(`pubspec.yaml` family `Pretendard`) — 네트워크 없이 같은 글꼴 |

- 글꼴 스택(웹): `"Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont, system-ui, Roboto, "Helvetica Neue", "Segoe UI", "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`.
  CDN 이 막혀도 시스템 한글 글꼴로 떨어지게 이 순서를 지킨다.
- 버전은 고정한다(`@1.3.9`). 올릴 때는 웹 두 링크와 앱 번들 파일을 같이 바꾼다.
- 예외는 하나: 프로필 카드의 구글 로그인 표시(`.pc-provider-google`)는 옛 구글 로고 오마주라 Georgia 세리프를 쓴다.

## 3. 형태 규칙
- 모서리: 카드/시트 28px, 버튼 14px, 칩 pill(완전 라운드).
- 그림자: `0 8px 32px rgba(93,64,55,.15)` (따뜻한 갈색 그림자 — 검정 금지).
- 오버레이/딤: `rgba(93,64,55,.35)` (검정 아닌 갈색 딤).
- 아이콘 모티프: 밥그릇 + 배구공(로고), 마커.

## 4. 보이스 & 토ン
- 친근하고 가벼움. "밥이름·도시락" 같은 **음식 비유**가 브랜드 정체성.
- 과장·전문용어 지양. 한 문장 = 한 메시지.

## 6. 에셋 제작 원칙 (일관성 고정)
- 모든 이미지: 크림 배경 + Pretendard + 누룽지 팔레트 + 실제 앱 스크린샷을 폰 목업 안에.
- 스크린샷은 **라이브 네이티브 앱(v2.0.0)** 에서 촬영 (웹뷰 구버전 금지).
- 한 시리즈(스토어/릴스)는 레이아웃 그리드·폰트 크기·여백을 고정해 통일감 유지.

## 7. 공유 카드 (앱·웹 공통 규격)
> 구현: 웹 `js/share.js`(팀·픽업 카드 + 공용 키트) · `js/my-card.js`(내 카드),
> 앱 `lib/widgets/share_card_kit.dart` · `story_card.dart` · `my_card.dart`.
> **두 구현은 이 표의 숫자를 그대로 쓴다.** 한쪽만 바꾸면 같은 카드가 플랫폼마다 달라진다.

### 7-1. 규격과 안전영역
| 규격 | 캔버스 | 안전영역(위·아래) | 쓰임 |
|---|---|---|---|
| 스토리 9:16 | 1080×1920 | 250 · 250 | 인스타 스토리. 위는 프로필·진행바, 아래는 답장바가 덮는다 |
| 피드 3:4 | 1080×1440 | 72 · 72 | 인스타 피드(2025~ 3:4 업로드·그리드), 카톡·저장용 |

- 좌우 여백 80 고정 → 본문 폭 920. 두 규격이 같은 폭이라 같은 요소가 같은 크기로 보인다.
- 머리글(로고+워드마크)은 안전영역 맨 위, 푸터(QR)는 안전영역 맨 아래에 붙인다.

### 7-2. 여백을 남기지 않는 배치 (탄력 요소)
- 카드마다 **탄력 요소 하나**가 남는 세로를 흡수한다. 고정 좌표로 배치하면 내용이 짧을 땐
  빈 띠가 생기고, 길 땐 푸터(QR)를 덮는다(2026-09 이전 카드의 실제 버그).
  - 팀·픽업: 지도 패널 (스토리 360~720, 피드 280~560)
  - 내 카드 네임카드: 도시락통 (280~760) · 내 카드 식단표: 시간표 (나머지 전부)
- 탄력 요소가 최소치보다 작아지면 정보 줄 수를 줄인다(제목 2→1줄, 이번주·정보 2→1줄) —
  잘라도 QR은 덮지 않는다. 최대치를 넘으면 본문 덩어리를 가운데로 모은다.

### 7-3. 토큰
| 토큰 | 값 |
|---|---|
| 간격 | 머리글↔본문 40, 블록 사이 32, 본문↔푸터 40 |
| 글자(px) | 표시 72/800 · 제목 60/800 · 섹션 36/800 · 본문 32/500 · 라벨 28/700 · 캡션 26/500 · 마이크로 22/700 |
| 최소 글자 | 20px (스토리를 폰에서 볼 때 약 7pt — 이보다 작으면 읽히지 않는다) |
| 모서리 | 카드 28, 칸 16, 칩·알약 완전 라운드 |
| 그림자 | `0 8 32 rgba(93,64,55,.15)` 하나. 알약·QR 타일은 `0 4 16 rgba(93,64,55,.12)` |
| 머리글 | 로고 원 56 + 워드마크 34/800, 좌측 기준선(80)에 붙임 |
| 푸터 | 헤어라인 + QR(스토리 172 · 피드 148, 흰 타일 여백 10) + SCAN · CTA 34/800 · URL 26/500 |

- **캔버스 안에는 이모지를 쓰지 않는다.** 앱 캔버스는 이모지가 □로 깨진다. 아이콘은 벡터로 그린다.

### 7-4. 내 카드 (포장하기) — 네임카드 · 식단표 두 장
목적으로 나눈 두 장, 둘 다 9:16(1080×1920). 미리보기 위 칩 두 개로 고르고 기본은 네임카드.
- **여백은 위아래 140** — 스토리 안전영역(위아래 250)을 다 비우지 않는다. 앱은 인스타 스토리에
  스티커로 붙이고(배경 위에 축소돼 얹힌다) 웹은 이미지로 저장하니 250을 비우면 위아래 빈 띠만 남았다.
  저장본을 스토리 배경으로 꽉 채워 올리면 위는 진행 바·프로필 줄, 아래는 답장 바가 덮으니 조금씩 남긴다.
  남는 세로는 탄력 요소(도시락통 · 시간표)가 먹는다.
- 앱 공유: 기본 버튼은 **인스타 스토리로 공유**(팀·픽업 카드와 같은 흐름 — 링크 자동 복사 + 첫 1회
  링크 스티커 안내), 옆에 다른 앱으로 공유(OS 공유시트).

**네임카드 — "나는 어떤 밥이야"** (밥 유형을 서로 비교하며 노는 게 출발점)
- 밥색 필드: [밥도감 No.NN · 희귀도] 알약 52 → 밥 이름 124/900(최소 72) → 한 줄 성격 32/600 →
  밥이름 · 가입일 28/700 → 대표팀 알약 60. 로고는 머리글에만 둔다(가운데 엠블럼 없음).
- 도시락통: 탄력 280~760. 칸 높이가 80 미만이면 칸 라벨(밥·국·반찬)을 빼고 이름만(색이 곧 칸).
- 밥도감 카드 324: 왼쪽 5×5 도장판(칸 44, 간격 10) — 모은 밥은 그 밥 색 + 갈색 테두리 3, 나는 먹색 테두리 6,
  못 모은 칸은 점선(전설 밥아저씨만 하늘색 `#81D4FA`). 오른쪽 '내 밥상 · 밥도감' 24 → 상차림 단계 64/900 →
  'N / 25종' 32/800 → '○○까지 N종 남았어요' 24/600.
- 스텁 CTA: '나는 무슨 밥일까?'

**밥도감 규칙** (웹 `js/profile.js` riceDex · 앱 `rice_dex.dart` — 같은 표)
- 번호 = `riceData` 순서(1~25). 희귀도 = 뽑기 가중치: 50 흔함 · 10 드묾 · 1 전설.
- 모은 수 = 나 + **밥친구 전체**의 밥 종류(중복 1번). 도감에 없는 이름(운영자 닉네임 등)은 세지 않는다.
- 상차림: 혼밥 1 · 밥상 2–5 · 한상차림 6–12 · 잔칫상 13–24 · 수라상 25. 단계 이름에 '누룽지'는 쓰지 않는다.
- 밥 종류마다 한 줄 성격(`rice_line_1`~`25`, KO/EN).
- 나가는 건 밥 종류뿐 — 친구 이름·팀·요일·시간은 어느 카드에도 없다. 합석 여부와도 상관없다.

**식단표 — "나 이번 주 이때 운동해"**
- 신원(왼쪽 정렬): 밥 색 점 + 밥이름 30/800 → 헤드라인 76/900(최소 52, 예: '화·목·토 저녁형',
  5일 이상이면 '주 N일 저녁형') → '주 N회 · N시간 코트 위' 32/700 → 팀 범례 알약 48(도시락 칸 색 점).
- 시간대 성향: 시작 17시 이후 저녁형 · 12시 이후 낮형 · 그 전 아침형, 많은 쪽.
- 시간표: 나머지 세로 전부(탄력). 칸 제목은 빼고(헤드라인이 제목) 블록 색 = 도시락 칸 색.
- 스텁 CTA: '같이 뛸 팀 찾기'
