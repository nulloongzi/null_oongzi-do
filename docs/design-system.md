# 누룽지도 디자인 시스템 (마케팅·프로덕트 공통)

> 웹·앱·마케팅 에셋(스토어 이미지·블로그·인스타·릴스)이 **한 톤**으로 보이게 하는 고정 규칙.
> 소스 진실: 웹 `css/main.css :root`, 앱 `lib/theme.dart`. 마케팅 에셋은 이 문서를 따른다.

## 1. 컬러 팔레트 (누룽지 톤)
| 토큰 | HEX | 용도 |
|---|---|---|
| nurungji-yellow | `#FAC710` | 메인 브랜드색, 강조 버튼/배지 |
| nurungji-brown | `#8D6E63` | 보조 텍스트, 아웃라인 |
| nurungji-dark | `#4E342E` | 제목/본문 텍스트 (배경 위) |
| nurungji-bg | `#FFF8E1` | 기본 배경 (따뜻한 크림) |
| nurungji-light | `#FFFDE7` | 카드/시트 배경 |
| urgent | `#FF7043` | 급구/주의 (픽업 마감 임박 등) |
| today | `#D84315` | "오늘" 강조 |
| white | `#FFFFFF` | 입력창/카드 표면 |

- 마케팅 이미지 배경 기본값: `#FFF8E1`(크림). 텍스트는 `#4E342E`.
- CTA/포인트에만 옐로 `#FAC710` 사용(남발 금지). 경고성 정보는 `#FF7043`.

## 2. 타이포그래피
- **폰트: Pretendard (가변)** — 웹·앱·마케팅 전부 동일. (앱 v2.0.0에서 통일 완료)
- 제목 800(ExtraBold), 본문 400~500, 캡션 400.
- 한글 우선, 영문 병기 시 같은 폰트.

## 3. 형태 규칙
- 모서리: 카드/시트 28px, 버튼 14px, 칩 pill(완전 라운드).
- 그림자: `0 8px 32px rgba(93,64,55,.15)` (따뜻한 갈색 그림자 — 검정 금지).
- 오버레이/딤: `rgba(93,64,55,.35)` (검정 아닌 갈색 딤).
- 아이콘 모티프: 밥그릇 + 배구공(로고), 마커.

## 4. 보이스 & 토ン
- 친근하고 가벼움. "밥이름·도시락" 같은 **음식 비유**가 브랜드 정체성.
- 과장·전문용어 지양. 한 문장 = 한 메시지.

## 5. 마케팅 에셋 규격 (이미지 뽑을 때 캔버스)
| 채널 | 사이즈(px) | 비고 |
|---|---|---|
| Play 스크린샷(폰) | 1080×1920 | 최소 2장, 권장 4~8장 |
| Play 피처 그래픽 | 1024×500 | 리스팅 상단 배너 |
| Play 앱 아이콘 | 512×512 | 기존 밥그릇+배구공 유지 |
| 인스타 피드 | 1080×1080 | |
| 인스타 스토리/릴스 | 1080×1920 | 세이프영역 상하 250px |
| 블로그 썸네일 | 1200×630 | OG 이미지 겸용 |

## 6. 에셋 제작 원칙 (일관성 고정)
- 모든 이미지: 크림 배경 + Pretendard + 누룽지 팔레트 + 실제 앱 스크린샷을 폰 목업 안에.
- 스크린샷은 **라이브 네이티브 앱(v2.0.0)** 에서 촬영 (웹뷰 구버전 금지).
- 한 시리즈(스토어/릴스)는 레이아웃 그리드·폰트 크기·여백을 고정해 통일감 유지.
