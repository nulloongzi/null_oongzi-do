## 1. Play Store 리스팅 카피

### 1-1. 앱 제목 (≤30자) — 택1
- `누룽지도 - 배구 동호회·픽업 지도` (19자) ← 권장(키워드 3개)
- `누룽지도 - 배구 동호회 지도` (16자) ← 기존 유지형

### 1-2. 짧은 설명 (≤80자)
```
내 근처 배구 동호회와 픽업 게임을 지도에서 한눈에. 지역·요일·대상으로 찾고 바로 참여하세요. 🏐
```

### 1-3. 전체 설명 (≤4000자)
```

"어디서 배구하지?"를 지도로 끝냅니다. 내 근처 동호회와 오늘 열리는 픽업 게임을
지도에서 바로 찾고, 지역·요일·대상(남·여·혼복·6인제)으로 걸러 나에게 맞는 팀을 만나세요.

■ 이렇게 쓰세요
· 지도에서 근처 배구 동호회 찾기 — 지역·요일·대상 필터
· 오늘/이번 주 픽업 게임 참여 — 급구 인원도 실시간으로
· 마음에 든 팀은 도시락🍱에 담아두기
· 팀 상세에서 회비·연습 시간표·인스타 릴스까지 한 화면에
· 우리 팀을 무료로 지도에 등록 — 신입 문의가 지도에서 들어옵니다

■ 누룽지도가 다른 점
· 순위도 별점도 없습니다. 모든 팀을 동등하게 — 초보도 편하게 문 두드리세요.
· 밥이름 닉네임🍚과 도시락🍱, 가볍고 친근한 배구 커뮤니티.
· English-OK: 외국인도 팀 찾기 쉽게 영어 표시를 지원합니다.
· 카카오/인스타 공유가 쉬워, 팀 홍보와 신입 모집이 한 번에.

■ 이런 분께
· 배구를 시작하고 싶은데 어느 동호회로 갈지 모르겠는 분
· 이사·전학으로 새 동네에서 팀을 찾는 분
· 오늘 당장 한 게임 뛰고 싶은 픽업 플레이어
· 신입을 모으고 싶은 동호회 총무

지금 지도를 열고, 가까운 코트부터 찾아보세요. 🏐

문의/지원: [지원 이메일 또는 nulloongzido.com]
```

## 3. 커뮤니티 침투 템플릿 (공급측=총무 등록 유도 우선)

### 3-1. 배구 카페/밴드 게시글 (긴 버전)
```
[무료] 우리 배구 동호회, 지도에 올려서 신입 받으세요 🏐

'누룽지도'는 전국 배구 동호회·픽업 게임을 지도에서 찾는 앱이에요.
가입 희망자들이 지역·요일·대상으로 팀을 찾는데, 등록 안 된 팀은 노출이 안 돼요.

· 등록 무료, 몇 분이면 끝 (팀명·지역·연습 요일·대상·회비·인스타)
· 순위·별점 없이 모든 팀 동등 노출 — 규모 작아도 불리하지 않아요
· 신입 문의가 지도/앱으로 바로 들어옵니다

앱: [Play Store 링크]  ·  웹에서 미리보기: nulloongzido.com
궁금한 점 댓글 주세요!
```

### 3-2. 오픈채팅·밴드 짧은 버전
```
전국 배구 동호회/픽업을 지도에서 찾는 '누룽지도' 앱이에요 🏐
우리 팀 무료 등록하면 신입이 지도에서 찾아와요. [링크]
```

### 3-3. 총무 DM 템플릿
```
안녕하세요! [팀명] 총무님이신가요? 😊
배구 동호회 찾기 지도 앱 '누룽지도'를 운영 중인데요,
[지역]에 팀이 아직 지도에 없어서요. 무료 등록해두시면 가입 희망자가
지도에서 바로 팀을 찾을 수 있어요. 등록 도와드릴까요? [링크]
```

> 주의: 각 카페/밴드의 홍보 규칙을 먼저 확인하고, 도배 금지. 한 커뮤니티당 1회, 운영진 문의 후 게시 권장.

## 4. 인스타 / 릴스 플라이휠 카피

### 4-2. 공식 계정 런칭 포스트
```
"어디서 배구하지?"를 지도로 끝내다 🗺️🏐
내 근처 동호회·픽업 게임을 한눈에. 순위 없이 모두 환영.
도시락🍱에 팀 담고, 밥이름🍚으로 시작하세요.
지금 다운로드 → 프로필 링크
#배구 #배구동호회 #배구모임 #픽업게임 #생활체육
```

### 4-3. 릴스 아이디어(짧게)
- "새 동네에서 배구 팀 찾는 법" 15초 — 앱에서 필터→팀 발견→도시락 담기 화면 녹화
- "픽업 게임 즉석 참여" — 급구 티커→상세→참여 흐름
- 총무 인터뷰: "지도 등록하고 신입 늘었어요" (사회적 증거)
